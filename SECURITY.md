# Security scope

Use the loopback service with a trusted OS account and trusted local MCP client. Never expose it to the Internet. Operator environment configuration can start a subprocess and must not be user-controlled in a hosted system. MCP clients receive private facts only when invoked by the user; do not connect a sensitive bank to an untrusted model or client.

Report vulnerabilities privately to the repository maintainer before disclosure. Do not include real resumes, credentials, session files or private exported facts in reports. This repository has no hosted data collection or telemetry.
